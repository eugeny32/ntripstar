# facade2dxf — облако точек LAS → DXF-подоснова фасада

Прототип автоматизации архитектурной отрисовки фасадов по облаку точек.
Принимает LAS/LAZ, находит плоскость фасада, детектирует проёмы и выдаёт
DXF-подоснову для доводки в AutoCAD, плюс ортофото фасада.

## Установка

```bash
pip install -r requirements.txt
```

## Использование

Файл RCS напрямую не читается (закрытый формат Autodesk) — экспортируйте
облако из ReCap в LAS/LAZ (или E57 → LAS через CloudCompare).

```bash
python3 facade2dxf.py облако.las -o фасад.dxf
```

На выходе:

| Файл | Что это |
|---|---|
| `фасад.dxf` | Подоснова в метрах: слои `FACADE_OUTLINE` (контур), `OPENINGS` (проёмы), `GAPS_REVIEW` (вероятные пропуски скана — проверить и достроить вручную) |
| `фасад_ortho.png` | Ортоизображение фасада по плотности точек (можно подложить в AutoCAD для трассировки декора) |
| `фасад_preview.png` | Превью с детекцией: зелёный — контур, синий — проёмы, красный — зоны на проверку |
| `фасад_meta.json` | Привязка координат DXF (u, v) к мировым координатам облака |

## Параметры

```
--res 0.02          разрешение растра, м/пиксель
--plane-tol 0.08    допуск RANSAC при поиске плоскости фасада, м
--slice 0.15        полутолщина среза вдоль фасада, м
--min-opening 0.15  минимальная площадь проёма, м²
--rect 0.85         порог прямоугольности: выше — проём, ниже — пропуск данных
```

Если облако шумное или стена неровная (штукатурка, руст) — увеличьте
`--plane-tol` и `--slice`. Если мелкие окна не находятся — уменьшите
`--min-opening`.

## Как это работает

1. **Плоскость фасада**: RANSAC-подгонка доминирующей прямой по проекции
   облака на план XY (ось Z считается вертикальной), уточнение МНК.
2. **Срез и проекция**: точки в пределах `--slice` от плоскости
   проецируются в координаты фасада (u — вдоль стены, v — высота).
3. **Растеризация**: карта плотности точек с шагом `--res`.
4. **Детекция**: внутренние «дыры» в плотности — кандидаты в проёмы.
   Прямоугольные (заполнение габарита ≥ `--rect`) считаются проёмами,
   нерегулярные — пропусками сканирования и уходят в `GAPS_REVIEW`.

## Ограничения прототипа

- Обрабатывается один (доминирующий) фасад за запуск. Для второго фасада
  того же облака вырежьте его зону заранее (CloudCompare / ReCap).
- Проёмы, примыкающие к краю фасада (двери в уровне земли), не выделяются
  отдельным прямоугольником — они остаются в контуре `FACADE_OUTLINE`.
- Пропуск скана, слившийся с окном, помечается одним прямоугольником в
  `GAPS_REVIEW` — окна внутри такой зоны достраиваются вручную по шагу
  соседних.
- Декор, карнизы и мелкая пластика не векторизуются — для них подложите
  `*_ortho.png` и обведите вручную.

## Тест на синтетике

```bash
python3 make_test_las.py       # стена 20x9 м, 18 окон, дверь, шум, окклюзия
python3 facade2dxf.py test_facade.las -o facade.dxf
```

Ожидаемый результат: ~14 окон в `OPENINGS`, зона окклюзии (с накрытыми ею
окнами) в `GAPS_REVIEW`, дверь в контуре фасада.
