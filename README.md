# facade2dxf — облако точек LAS → DXF-подоснова фасада

Прототип автоматизации архитектурной отрисовки фасадов по облаку точек.
Принимает LAS/LAZ, находит плоскость фасада, детектирует проёмы и выдаёт
DXF-подоснову для доводки в AutoCAD, плюс ортофото фасада.

## Установка

```bash
pip install -r requirements.txt
```

## Графический интерфейс (FacadeStudio)

```bash
python facade_gui.py
```

Порядок работы:
1. **Обзор...** → выбрать LAS → **Загрузить облако** (появится план сцены).
2. **Автопоиск фасадов** — найдёт все стены; список слева, оси на плане.
3. Клик по фасаду в списке — его линия подсвечивается на плане (зелёная,
   с полосой среза пунктиром), а во вкладке «Превью фасада» показывается
   результат детекции.
4. Правка: концы зелёной линии перетаскиваются мышью; толщина среза —
   в параметрах. **Обработать линию/пересчитать** пересчитывает выбранный
   фасад (или добавляет новый, если ничего не выбрано).
5. **Нарисовать линию фасада** — задать плоскость вручную двумя кликами
   по плану (для стен, которые автопоиск пропустил).
6. Результаты (DXF, ортофото, превью) пишутся в папку исходного LAS —
   кнопка «Открыть папку результатов».

### Сборка exe (Windows)

Запустите `build_exe.bat` в папке проекта — он установит PyInstaller и
соберёт `dist\FacadeStudio.exe` (самодостаточный, Python на целевой
машине не нужен). Windows SmartScreen при первом запуске неподписанного
exe может спросить подтверждение — «Подробнее» → «Выполнить в любом
случае».

## Использование (командная строка)

Файл RCS напрямую не читается (закрытый формат Autodesk) — экспортируйте
облако из ReCap в LAS/LAZ (или E57 → LAS через CloudCompare).

```bash
python3 facade2dxf.py облако.las -o фасад.dxf
```

Скрипт сам находит все вертикальные плоскости сцены (до `--facades`, по
умолчанию 8), включая все 4 стороны здания, и разделяет разные здания,
стоящие на одной линии. Земля, отмостка и низкий мусор отбрасываются
фильтром вертикальности автоматически.

На выходе для каждого найденного фасада `_fNN`:

| Файл | Что это |
|---|---|
| `фасад_fNN.dxf` | Подоснова в метрах: слои `FACADE_OUTLINE` (контур), `OPENINGS` (проёмы), `GAPS_REVIEW` (вероятные пропуски скана — проверить и достроить вручную) |
| `фасад_fNN_ortho.png` | Ортоизображение фасада по плотности точек (можно подложить в AutoCAD для трассировки декора) |
| `фасад_fNN_preview.png` | Превью с детекцией: зелёный — контур, синий — проёмы, красный — зоны на проверку |
| `фасад_fNN_meta.json` | Привязка координат DXF (u, v) к мировым координатам облака |

Плюс общий `фасад_scene_plan.png` — вид сцены сверху с осями и номерами
найденных фасадов, чтобы сопоставить `fNN` со сторонами зданий.

## Параметры

```
--facades 8         максимум фасадов за запуск (1 — только доминирующий)
--res 0.02          разрешение растра, м/пиксель
--plane-tol 0.08    допуск RANSAC при поиске плоскости фасада, м
--slice 0.15        полутолщина среза вдоль фасада, м
--min-opening 0.15  минимальная площадь проёма, м²
--rect 0.85         порог прямоугольности: выше — проём, ниже — пропуск данных
--max-points 15e6   прореживание облака до N точек
--gap 3.0           разрыв в плане, разделяющий здания на одной линии, м
--min-facade-len 4  минимальная длина фасада, м
```

При редком облаке растр укрупняется автоматически (в консоли будет
пометка) — для детализации поднимите `--max-points` или вырежьте зону
одного здания из облака.

Если облако шумное или стена неровная (штукатурка, руст) — увеличьте
`--plane-tol` и `--slice`. Если мелкие окна не находятся — уменьшите
`--min-opening`.

## Как это работает

1. **Плоскость фасада**: RANSAC-подгонка доминирующей прямой по проекции
   облака на план XY (ось Z считается вертикальной), уточнение МНК.
2. **Срез и проекция**: точки в пределах `--slice` от плоскости
   проецируются в координаты фасада (u — вдоль стены, v — высота).
3. **Растеризация**: карта плотности точек с шагом `--res`.
4. **Детекция**: внутренние «дыры» в плотности — кандидаты в проёмы.
   Прямоугольные (заполнение габарита ≥ `--rect`) считаются проёмами,
   нерегулярные — пропусками сканирования и уходят в `GAPS_REVIEW`.

## Ограничения прототипа

- Фасад, закрытый баннером/плакатом, сканер видит как глухую стену —
  проёмы за баннером в облаке отсутствуют и дорисовываются по фото.
- Проёмы, примыкающие к краю фасада (двери в уровне земли), не выделяются
  отдельным прямоугольником — они остаются в контуре `FACADE_OUTLINE`.
- Пропуск скана, слившийся с окном, помечается одним прямоугольником в
  `GAPS_REVIEW` — окна внутри такой зоны достраиваются вручную по шагу
  соседних.
- Декор, карнизы и мелкая пластика не векторизуются — для них подложите
  `*_ortho.png` и обведите вручную.

## Тест на синтетике

```bash
python3 make_test_las.py       # стена 20x9 м, 18 окон, дверь, шум, окклюзия
python3 facade2dxf.py test_facade.las -o facade.dxf
```

Ожидаемый результат: ~14 окон в `OPENINGS`, зона окклюзии (с накрытыми ею
окнами) в `GAPS_REVIEW`, дверь в контуре фасада.
